How to use
Each coloured outline is one linear map applied to the black seed triangle. The drawing applies all maps over and over, down to the chosen depth.

Select a map by tapping its outline. Drag inside it to move it. In Move / scale mode, corner handles scale uniformly (Shift: free), edge handles stretch one axis. In Rotate / shear mode, corner handles rotate about the centre (Shift: snap to 15°), edge handles shear. Tapping a selected map toggles the mode.

Drag empty space to pan, use the wheel or pinch to zoom. Arrow keys nudge the selected map, Delete removes it. The link in the address bar encodes the whole figure.
